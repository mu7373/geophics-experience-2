# 实验二：机械臂仿真（二）

本仓库基于实验一的场景树、正运动学与示教器扩展，实现逆运动学、MOVJ/MOVL、坐标系校正和机械臂操作语言。

## 目录

```text
robot-arm-lab2/
├─ index.html             入口页面
├─ css/                   页面样式
├─ js/                    所有 JavaScript 模块
│  ├─ app.js              页面装配与事件绑定
│  └─ contracts.js        三人共用接口，先冻结再实现
├─ images/                截图、录屏封面、模型与模型数据
│  └─ models/             从实验一迁移的 GLB、关节限位和模型结构数据
├─ 任务分配.md             三人分工、依赖和验收标准
└─ README.md              项目说明与协作规则
```

## 启动方式

首次运行先安装依赖：

```bash
npm install
npm start
```

随后打开 `http://127.0.0.1:8123`。模型已从实验一迁移到 `images/models/`，由 `js/app.js` 统一加载。

## 开发顺序

1. 先从实验一移植已验证的模型加载、关节控制、FK 和示教点记录代码。
2. 成员 1 完成 IK、MOVJ/MOVL 规划和碰撞粗检测，并实现 `motionApi`。
3. 成员 2 完成工具系四点法、用户系三点法与四种坐标点动，并实现 `calibrationApi`。
4. 成员 3 完成 DSL 解析器、状态机执行器、夹爪与急停，并实现 `programApi`。
5. 三人以 `js/contracts.js` 为唯一接口契约联调，最后录制抓取—搬运—放置演示。

## GitHub 协作约定

- 每个人只修改自己负责的 JS 文件；公共接口改动必须先在组内确认。
- 提交信息使用 `feat: 实现 MOVL 插补`、`fix: 修复用户系点动方向` 这类清晰描述。
- 不提交 `node_modules/`、浏览器缓存或临时录像；验收截图统一放 `images/`。
- 合并前至少检查：页面能加载、浏览器控制台无报错、基础脚本能被解析。
